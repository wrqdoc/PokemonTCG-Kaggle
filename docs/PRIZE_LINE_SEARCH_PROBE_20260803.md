# Prize 线精确搜索：探针与 A/A 对照

日期：2026-08-03
状态：**已否决。** 原始效应的 73% 是可证的 max-of-noise，剩下的 +2.67 pp 不显著（z=1.55, p=0.12）。
脚本：`P/probe_prize_line_search.py`

## 0. 为什么做这个

`D/SEARCH_OFFLINE_VERDICT_20260803.md` 否掉的是**用学出来的 value net 给动作排序**的搜索。
失效原因是评估器的排序方向是反的。那么自然的下一问：

> 换一个**目标本身就是精确、模拟器可直接验证**的搜索，同一个失效模式还会出现吗？

选定的目标：**从我方回合开始，是否存在一条 MAIN 动作序列，本回合拿到的 prize 严格多于 BC 的贪心线？**

"本回合拿了几张 prize"是真值，不是学出来的分数，也不是"与专家一致"这种代理指标。

## 1. 设计

- **一个回合一个根节点**（每个 (seat, turn) 的第一个 MAIN 根节点），不是一个决策一个。
  ⚠️ 该根节点的 `turnActionCount` 是 **1** 不是 0——强制抽牌占掉了 0。
- **只在 MAIN 分叉**；子选择（弃哪张、打哪个目标）交给 BC。在 8 张里选 3 张弃是组合爆炸，
  且不是本实验要测的部分。
- 每根节点有硬节点预算；打满预算的根节点单独统计。
- **每个叶子都必须是"打完的回合"。**

⚠️ **踩过的坑**：第一版在预算耗尽时直接给**没打完的回合**记分，于是报出
`best (0.65) < bc (0.75)`——这是不可能的，因为 BC 自己的线就在搜索空间里。
`best >= bc` 是这个实验的**不变量**，任何时候它不成立就是有 bug。

## 2. 原始结果（n=900 回合，预算 600 节点）

| 指标 | 值 |
|---|---:|
| BC 每回合拿到的 prize | 0.643 |
| 搜索能拿到 | 0.770（**+19.7%**） |
| 有更好线的回合 | 10.00%（95% CI [8.04, 11.96]） |
| 每回合多拿 | +0.127 |
| BC 拿 0 但存在能拿的线 | 7.78% |
| 打满节点预算的比例 | 84.9% |

分布：810 个回合 gap=0，70 个 +1，16 个 +2，4 个 +3。

**看起来很大。但下面这条让它可疑。**

## 3. ⚠️ 一个致命的替代解释

按是否打满预算拆开：

| | n | 有更好线的比例 |
|---|---:|---:|
| 打满预算（探索多） | 764 | **11.78%** |
| **搜完了整个空间** | 136 | **0.00%** |

**把整个空间搜完的回合，BC 一次都没漏过 prize。** 全部"收益"来自探索得多的回合。

替代解释：**每次 `search_step` 都推进模拟器 RNG，不同前缀会摸到不同的牌。
搜索是在几百条线上取 max —— 那就是在对噪声取最大值。** 探索越多，max 抬得越高。
这与上表完美吻合。

## 4. A/A 对照：一半以上是噪声

把 BC **自己那条一模一样的线**重复 12 次取 max（动作完全相同，只有 RNG 不同）：

| | n | 有"更好"线的回合 | 95% CI | 每回合多拿 |
|---|---:|---:|---|---:|
| **A/A 对照（k=12）** | 900 | **5.22%** | [3.77, 6.68] | 0.060 |
| 真实搜索（600 节点） | 900 | 10.00% | [8.04, 11.96] | 0.127 |

**重复同一条线就能凭空变出 5.22% 的"改进"。** 原始的 +19.7% 里，超过一半是 max-of-noise。

### 4.1 但 k=12 的噪声底还不够

真实搜索每根节点评估了**中位 181 个完整回合**（叶子计数实测：mean 175、p90 264、max 329），
而对照只取了 12 次 max。**取 max 的样本越多，噪声底越高**，所以 k=12 的 5.22% 是**低估**。

正确做法是把噪声底测成 **max-of-k 的曲线**并看它饱和在哪：
`--null-control --null-repeats 64` 一次跑记录 k=1,2,4,8,16,32,64 的完整曲线。

**A/A 噪声底曲线**（n=300 回合，重复 BC 自己那条一模一样的线，取前 k 次的 max）：

| k | 有"更好"线的回合 | 均值 gap | 95% CI |
|---:|---:|---:|---|
| 1 | 1.00% | 0.010 | [−0.13, 2.13] |
| 2 | 2.00% | 0.023 | [0.42, 3.58] |
| 4 | 3.67% | 0.047 | [1.54, 5.79] |
| 8 | 4.33% | 0.053 | [2.03, 6.64] |
| 16 | 5.67% | 0.067 | [3.05, 8.28] |
| 32 | 6.00% | 0.070 | [3.31, 8.69] |
| 64 | **6.33%** | 0.073 | [3.58, 9.09] |

曲线明显饱和：最后三次翻倍每次只加 **0.67 pp**。按此外推到真实搜索的中位叶子数 k=181：
**噪声底 ≈ 7.33%**。

### 4.2 判定

| | 值 |
|---|---:|
| 真实搜索 | 10.00%（n=900） |
| 外推噪声底（k=181） | 7.33% |
| **超出噪声底** | **+2.67 pp** |
| SE | 1.73 pp |
| **z = 1.55，p = 0.12** | **不显著** |

**原始效应的 73%（按回合比例）/ 58%（按均值 gap）是可证的 max-of-noise，
剩下的部分达不到显著。**

⚠️ 报告任何来自"多条采样线取 max"的 gap 时，**必须先减掉同 k 的噪声底**。
原始的 +19.7% 如果直接写进交接文档，就是本项目第二次"离线大效应经正确校正后蒸发"。

## 5. 无论曲线结果如何都成立的一条：max 是错误的运行时目标

这不只是测量假象，**同一个机制会让运行时实现拿不到收益**：

按"某一次随机 rollout 下哪条线看起来最好"来选，选中的就是噪声的最大值。
真实对局的抽牌顺序与那次采样不同，这部分收益一分都拿不到——
这是不完全信息搜索里 determinization + max 的经典病。

**所以正确的目标不是"采样出来能拿最多 prize 的线"，而是"不依赖未知抽牌就能确定拿到的 prize"。**

可操作的判据：一条线只有在**多次独立确定化下都**达成该 prize 数才算数——
取**多次确定化的最小值**（或多数），而不是最大值。最小值对噪声免疫：
一条靠运气摸到关键牌的线，换个确定化就失败，会被自动剔除；
而"我手上已经有能量和攻击者，现在打就 KO"这种线在任何确定化下都成立。

**这个改造没有做，也不建议做**（2026-08-03 决定）：
min-over-D 只会找到 max-over-1 所找到的**子集**（在所有确定化下都成立的线，
是在某一次确定化下成立的线的子集）。而 max 版本超出噪声底的部分只有 +2.67 pp 且不显著，
子集只会更小。**为一个未被证实的、上限 2.67 pp 的效应再建一套实验，正是不该做的事**
（见主计划 §5 的"不要把 σ 读成先去把尺子磨准"）。

若将来有人重开这条线，门槛是：**先证明超出噪声底的部分显著**，再谈实现。
